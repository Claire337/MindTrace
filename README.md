## 🛠️ Frequently Asked Questions

### Q: How do I reset all data?
```bash
source venv/bin/activate
python3 seed.py
```
Enter `y` to confirm clearing the data.

### Q: How do I change the demo account password?
Edit `seed.py`:
```python
demo_user = User(
    email='demo@mindtrace.app',
    username='demo',
    password='Your_New_Password'  # Change it here
)
```
Then run `python3 seed.py` again.

### Q: How do I stop the application?
Press `Ctrl + C` in the terminal.

### Q: How do I change the port number?
Edit the last line of `run.py`:
```python
app.run(host='0.0.0.0', port=8000)  # Change the port
```

### Q: What should I do if I get a "ModuleNotFoundError" error?
Make sure the virtual environment is activated:
```bash
source venv/bin/activate
```

### Q: Why is the page loading slowly?
This is normal in the development environment. It will be faster in production when using Gunicorn.

## 🔧 .env File Configuration

Create a `.env` file (if it does not exist):

```bash
cat > .env << 'EOF'
FLASK_ENV=development
FLASK_DEBUG=True
SECRET_KEY=your-secret-key-here-change-in-production
SQLALCHEMY_DATABASE_URI=sqlite:///mindtrace.db
BABEL_DEFAULT_LOCALE=en
LANGUAGES={'en': 'English', 'zh': 'Chinese'}
LLM_PROVIDER=openai
LLM_API_KEY=your-api-key-here
LLM_MODEL=gpt-3.5-turbo
LLM_BASE_URL=https://api.openai.com/v1
EOF
```
